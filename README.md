# Farmácia API REST

## Sobre o projeto

Este projeto consiste no desenvolvimento de uma API REST para uma rede de farmácias com duas filiais, oferecendo opções de retirada na loja ou entrega.

O sistema tem como objetivo gerenciar pedidos, produtos, estoque por filial, reservas, documentos para validação, retirada e acompanhamento de entregas.

## Objetivo

Desenvolver uma API Back-End capaz de organizar o fluxo de atendimento da farmácia, garantindo a integridade das informações, o controle de estoque e a segurança no acesso aos dados.

## Funcionalidades previstas

- Cadastro e consulta de produtos.
- Controle de estoque por filial.
- Criação e consulta de pedidos.
- Reserva de produtos.
- Envio e validação de documentos.
- Separação de pedidos.
- Alteração da modalidade de recebimento.
- Geração e validação de códigos de retirada.
- Acompanhamento de entregas.

## Tecnologias

- JavaScript
- Node.js
- API REST
